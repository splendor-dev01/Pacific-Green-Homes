# Pacific Green Homes website

React + TypeScript + Vite website project.

## Run locally

1. Install Node.js (20 or newer).
2. From this folder, run `npm install`.
3. Run `npm run dev` and open the local address Vite prints.

## Production build

Run `npm run build`; Vite writes the deployable site to `dist/`.

The `public/` directory contains the site's images, videos, and scroll-animation frames. `package-lock.json` is included for reproducible installs.

This source archive omits `.git/`, `node_modules/`, and the generated `dist/` output; Git metadata and installed/build artifacts can be regenerated or recreated as needed.
